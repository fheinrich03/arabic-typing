# arabic-typing

## Git

- Work directly on `main`. Do not create a feature branch unless explicitly asked to.
  This overrides the general "one branch per issue" rule.
- Commit on your own, without asking, whenever a task is done or the code reaches a
  runnable state (build passes). Frequent intermediate commits are welcome. Don't push
  unless asked.

## UI

- Use shadcn components (`src/components/ui/`, style `base-nova`) instead of hand-rolled
  equivalents. Add missing ones with `npx shadcn add <component>`.
